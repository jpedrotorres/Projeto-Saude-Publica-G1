Sobre o projeto

Este projeto realiza uma análise exploratória e visualização dos indicadores de saúde pública presentes na base de dados utilizada no trabalho.


O objetivo é explorar o comportamento dos indicadores ao longo do período analisado, permitindo comparações entre regiões, estados e demais dimensões presentes na base de dados.


A análise utiliza técnicas de manipulação, agregação, visualização e análise estatística dos dados, complementadas por um dashboard interativo desenvolvido com Streamlit.

Principais análises

📈 Evolução temporal

Análise do comportamento dos indicadores ao longo dos anos representados na base de dados.

🗺️ Análise regional

Comparação dos indicadores de saúde entre as diferentes regiões e estados presentes nos dados.

🏥 Infraestrutura

Análise da distribuição dos leitos hospitalares entre os estados representados na base.

🔬 Correlação

Investigação das relações lineares entre os principais indicadores numéricos por meio de matriz de correlação e gráficos.

Indicadores analisados

Expectativa de vida

Indicador utilizado para analisar a expectativa de vida presente na base.

Taxa de mortalidade

Indicador utilizado para analisar o comportamento da mortalidade nos diferentes recortes.

Cobertura vacinal

Indicador relacionado à cobertura vacinal registrada nos dados.

Taxa de internação

Indicador utilizado para analisar a taxa de internação presente na base.

Médicos por 1.000 habitantes

Indicador relacionado à disponibilidade de médicos representada nos dados.

Leitos hospitalares

Indicador utilizado na análise da infraestrutura hospitalar.

Doenças crônicas

Indicador relacionado aos casos de doenças crônicas presentes na base.

Nível de criticidade

Classificação utilizada para analisar os registros segundo o nível de criticidade disponível nos dados.

Tecnologias utilizadas

🐍 Python

Linguagem principal utilizada no desenvolvimento do projeto.

📊 Pandas

Manipulação, tratamento e análise dos dados.

📈 Matplotlib

Construção das visualizações utilizadas na análise.

📉 Seaborn

Construção de visualizações estatísticas, incluindo heatmaps.

🌐 Streamlit

Desenvolvimento do dashboard interativo.

🗄️ SQLite

Persistência dos dados utilizados pela aplicação.

📓 Jupyter

Desenvolvimento e documentação da análise exploratória dos dados.

Dashboard interativo

O dashboard permite explorar os dados de forma interativa, utilizando filtros por período, região, estado, município e nível de criticidade.


Os indicadores e visualizações são atualizados de acordo com o recorte selecionado pelo usuário.
